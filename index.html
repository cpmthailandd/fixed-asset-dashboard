ทำได้แน่นอนครับ! โดยการเปลี่ยนให้หน้าเว็บกลายเป็น ระบบจัดการข้อมูลแบบ 2 ทาง (Read & Write) การจะทำระบบนี้จะต้องมีตัวกลางในการรับ-ส่งข้อมูล ซึ่งวิธีที่ง่าย สะดวก และฟรีที่สุด คือการใช้ Google Apps Script (Web App) เข้ามาเป็น API ครับ กลไกการทำงานเมื่ออัปเกรดเป็นระบบแก้ไขผ่านหน้าเว็บ: บนหน้า Dashboard (HTML): แต่ละแถวในตารางจะมีปุ่ม "แก้ไข" (Edit / ไอคอนดินสอ) เพิ่มขึ้นมา เมื่อคลิก จะมีหน้าต่างป๊อปอัป (Modal) เด้งขึ้นมาพร้อมแบบฟอร์มให้แก้ไขข้อมูล เช่น เปลี่ยนผู้ครอบครอง (Assigned To), เปลี่ยนสถานะ (Status: In Use / Spare / Broken), หรือแก้ไขราคาทุน เมื่อกดปุ่ม "บันทึก" (Save) หน้าเว็บจะส่งข้อมูลที่แก้ไขแล้วไปยัง Google Apps Script Google Apps Script (ตัวกลาง): จะไปค้นหาแถวของรหัสนั้นใน Google Sheets แล้วทำการอัปเดตข้อมูลในช่องที่แก้ไขให้อัตโนมัติทันที ส่งสัญญาณกลับมาบอกหน้าเว็บว่า "บันทึกสำเร็จ" และตารางจะอัปเดตข้อมูลใหม่ให้ทันที คุณอยากให้อัปเกรดเป็นระบบนี้เลยมั้ยครับ?
